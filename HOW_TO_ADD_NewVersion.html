🚀 Adding a New Chat Version (V3)

This guide explains how to safely add a new WebSocket chat version without breaking existing versions. Follow these steps every time you create V3, V4, or beyond.

🧠 Architecture Rule

Each chat version has its own Fragment, but shares:

  • 🔁 One global WebSocket connection
  • 🧩 One common Conversation UI
  • 🗂 Isolated message history per version

🪜 Step-by-Step: Create V3

1
Create Fragment ConversationV3Fragment.kt Copy an existing version fragment and rename:
  • Class name → ConversationV3Fragment
  • Channel name → ws-v3
  • Log tag → V3
2
Register Navigation <fragment android:id="@+id/nav_ws_v3" android:name="...ConversationV3Fragment" android:label="WebSocket V3" />
3
Add Version Entry ChatVersion( id = "ws_v3", navId = R.id.nav_ws_v3, title = "WebSocket V3" ) No drawer changes needed.

💬 Message Isolation

Each version keeps its own history using:

ConversationMessageStore.messages("ws-v3") Switching between versions will never mix messages.

✅ Final Checklist

🎉
V3 is ready!
  • Drawer shows V3 automatically
  • Socket connects only once
  • V1, V2, V3 states are isolated
